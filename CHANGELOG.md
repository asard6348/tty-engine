# Changelog

## 0.2.3

- Fixed: setting an object's text to an empty string left its old glyphs on screen. The compositor skipped objects with empty text, so the cells they had occupied were never redrawn; they are now cleared.

## 0.2.2

- Fixed: mouse movement without a pressed button was reported as a `release` event by terminals that send it in the legacy X10 encoding or with an `m` final in the SGR encoding, so `onmouse('move', ...)` never fired and code that draws or aims while a key is held saw no movement. Motion is now recognised from its motion bit before the press or release is considered, the X10 parser also reports `move` for dragging and handles the wheel, and `click` and `release` are no longer fired for motion.

## 0.2.1

- Collision queries use a uniform-grid broadphase (`ttyengine.broadphase`) kept in sync with `scene.solids`, so each body only tests the solids near its path instead of every solid in the scene. Large bodies are tracked separately and never scanned cell by cell.
- Axis movement jumps straight across free space: a body measures the clear distance to the nearest solid along its lane and only steps by `precision` near obstacles. Fast and huge bodies no longer pay for every sub-step, and contacts still resolve at the same positions.
- Rotation sub-steps are skipped when nothing is within reach of the rotating body, and the results of `transform.rotate` are memoized per angle bucket and shape, so spinning bodies reuse their rasterized layout.
- Collision pixels are built from per-row spans instead of per-character loops, and penetration depth is found with per-row bit masks instead of repeated set intersections.
- The mixer sums plain-speed voices as packed integer lanes instead of per-sample Python lists, which is several times faster with many voices and produces identical output.
- The broadphase query has a single-cell fast path and sorts only when needed, and a body's probe runs one query for its whole reach instead of one per direction.
- Callback signature inspection is cached per callable in the scene, shared helpers, sound and input handler, so dispatching callbacks no longer calls `inspect.signature` every time.
- Stacked colour codes are collapsed to the last foreground and background before output, so styles that accumulate escape codes no longer make frames grow quadratically. Terminal output looks the same.
- Lights skip cells outside their reach, shadow rays test only the solids overlapping the ray, and light style strings are parsed once and cached.
- Contact normals are fitted with row bit masks and lookup tables instead of a per-cell scan: each body keeps its solid cells as per-row integers, the circular fitting window is a cached mask per row, and sums come from the set bits of each masked row. Fits are memoized by shape content, bounded by size, so resting contacts reuse them. Results match the cell-by-cell fit except where float noise decided an exact tie.
- `transform.rotate` memoizes rasterized layouts in one shared store bounded by total size and guarded by a lock, instead of 128 entries per object, so identical shapes and angles are computed once for the whole scene.
- Rotation and the change-callback bookkeeping write their private fields directly instead of through the revision-tracking `__setattr__`, which keeps rotation-heavy scenes at their previous speed.
- `transform` counts every attribute write in `_rev`, `scene.objs` counts every mutation, and `obj` counts component attach and detach. The compositor skips objects whose revision and scene environment (camera, offsets, ambient, colours, light versions) are unchanged, and keeps the z-sorted sprite list, updating it in place when only positions or text change. A frame with one moving object among thousands no longer visits every object.
- `Scene.tick` visits only objects that have a physics, animating or joint/light component, using a roster cached against those counters; if a callback adds, removes or re-equips objects mid-phase the remaining objects are visited exactly as before.
- Colour changes between neighbouring runs are written as the changed codes only, with no reset, when both styles consist purely of foreground and background colours and no escape wrapper is active. Frames are 12 to 45 percent smaller in colourful scenes and render to the same screen.
- Frame diffs are computed with `bytes(map(operator.ne, ...))`, camera rotation hoists its per-column and per-row terms without changing a single float operation, and glow shadows reject solids outside a row's vertical reach once per row instead of once per cell.
- `Session.run` raises the garbage collector's generation 0 threshold while running, restoring it on exit, unless the application already changed it, which shortens frame-time spikes.
- A solid body turns in a single step whenever no other object can be within reach of its swept shape. The reach is the farthest cell from the shape's centroid plus a 4 cell margin that covers every rasterization offset measured, instead of the bounding box diagonal plus 3 cells on each side, which made almost any neighbour force a rasterization and an overlap test for every 3 degree piece. A large sprite spinning near a wall costs a single rasterization per frame.
- When a large body cannot turn in one step, it measures its real clearance to the nearby solid cells with bit masks (the neighbours' cells grown by the reach of the swept shape) and turns by the largest whole number of pieces that clearance proves cannot touch anything, never more than 60 degrees at a time; the remaining pieces near a contact are tested one by one exactly as before, so contacts are found at the same angles.
- `rprecision` is now automatic by default: a rotation piece moves the outermost cell by at most `precision` cells in x, and never less than the previous fixed 3 degrees, so small bodies take fewer pieces and large bodies behave as before. Assign a number (for example `rprecision=3`) to pin the previous behaviour exactly, or `None` to return to automatic. Contacts of small bodies can register up to a couple of coarser pieces later; bodies still cannot turn through a thin solid.
- The rotation layout finds the cells enclosed on all four sides with bit masks on whole rows instead of counting neighbours cell by cell, and produces exactly the same cells in the same order.
- Fixed: rotating a dense image no longer scatters pixels. When two glyphs wanted the same cell, the loser went to the nearest free cell, one loser at a time, so later ones could end up many cells away (up to 10) and gap filling then drew streaks towards them; on images whose characters or colours change from cell to cell these showed as stray pixels that moved every frame. A glyph may now be placed at most 1.5 units from its exact rotated position; a cell beyond that keeps its place in the shape but takes the nearest real glyph within 1.5 units, and is dropped only when no glyph is that close. Text, ASCII art and outlines come out as before in all but about 0.4 percent of layouts, and a rotated solid block keeps its footprint apart from a rare fringe cell.
- Fixed: for single character sprites the inverse rotation coefficients used by `world_to_rtextf` and `cutline` kept the values of the first angle the sprite was rotated to; they now follow the current angle.
- Fixed: changing `scene.bgcolor` now repaints the view; before, already drawn cells kept the old background until something else redrew them, which also left background fades stuck.
- Fixed: changing an object's `z` (`front()`, `back()`, `z =`) now repaints the object; before, the new stacking order only appeared after something else redrew that area.
- JPEG decoding skips zero coefficients in the inverse DCT and PNG decoding unfilters Up and Sub rows with packed integer lanes and converts whole rows at once for 8-bit non-interlaced images. Decoded pixels are identical.
- New `handle.wait(duration, frames=False)` suspends the `start`, `update` or `final` function that calls it and continues from the next line, while the engine and the handle's other functions keep running. `handle.until(condition, timeout=None, frames=False)` does the same until a condition is true and returns whether it was met. Outside such a function `wait` sleeps and `until` raises `RuntimeError`. Functions that never mention `wait` or `until` run exactly as before.
- New `handle.after(delay, fn, frames=False)` and `handle.every(interval, fn, frames=False, delay=None)` run a callback later or repeatedly from the frame loop. Both return a `Task`, which can also be created directly with `Task(handle, fn, delay, interval, frames)` and is exported as `ttyengine.Task`. `task.cancel()` (or `world.cancel(task)`) stops a timer or a function suspended in `wait` or `until`, `handle.tasks` lists a handle's live tasks, and `handle.cancel()` cancels them all.
- `pause` on `Handle`, `World` and `Session`, and `pausephysics` and `pauserendering` on `World` and `Session`, are now properties that store a bool. While a handle, its world or the session is paused, the time of its waits and timers stands still.

## 0.2.0

- `joint` gains angular settings for pinned joints: `limit` is a `(low, high)` range of the follower's rotation relative to its origin, `target` turns the follower toward an angle with a motor, `gain` (default `0.5`) is the share of the remaining angle the motor closes per tick, and `effort` caps the angular impulse per tick (unset means unlimited). Limits and motor exchange equal and opposite angular impulses between the two bodies, so angular momentum is conserved.
- Limp `humanoid` joint limits are enforced by the `joint` `limit` setting instead of by the humanoid itself, and `humanoid` no longer has a per-tick step.
- `humanoid` parts collide like any other body unless told otherwise: a part's `solid` (`True` or `False`) wins over the figure's `solid`, which is a bool or a list of part or group names and defaults to `None`, meaning every part. `ragdoll(solid=None)` keeps each part's own setting and `solid=True` makes every part collide while limp. The `contact` part setting is gone. A stiff figure's root is no longer spun by joint torque, since its orientation is set by `pose`.
- The `humanoid` `tether` setting and the `snap` setting of `humanoid` and `joint` are removed. `elasticity` has no `humanoid` default of its own: left unset, every joint keeps its own `joint` default of `1`, and a limp figure's pins use the elasticity of their joint.
- Part sizes in a `humanoid` layout ignore a trailing newline the way the renderer does, so a limb written as `'█\n' * 3` is three rows tall and the part hanging from it no longer starts one row too low, which left a one-cell gap between thigh and shin. The new `spaces` setting (humanoid-wide or per part, default `False`) turns this off, so `spaces=True` counts the empty last line as a row again.
- `humanoid.pose` accepts the name of a registered pose as well as a dict.
- `ontouch` callbacks now fire whenever bodies really collide: after a rotation hits something, for rotating phantoms and non-solid bodies, and when the resting-contact pass applies a collision impulse. Before, a spinning body could knock another one away without either being notified.
- Limp humanoids are articulated rigid bodies: limbs are pinned ball joints with their own inertia and angular velocity, joint limits are angular impulses, and `elasticity` sets the pin stiffness.
- Rotated shapes are rasterized from the angle bucket itself, so a body's cells no longer depend on the path its rotation took, and visuals use the same angle as collisions.
- Contact normals are fitted to the boundary cells of each surface and assigned to the face rather than the corner, so blocks slide down slopes and stay on them according to friction versus `tan(angle)`, and normals stay vertical near the ends of flat surfaces.
- Non-solid bodies are no longer pushed out of solid objects they overlap, and a rotation that is undone restores the exact previous angle.

- New `ttyengine.net` package for UDP and TCP servers, clients and peer-to-peer meshes with no dependencies. `Node` hosts, connects, relays and sends messages on named channels; `Sync` shares a session, world, scene, object or single variable with every connected node, with per-entity and per-variable ownership, reliable or latest-wins updates, late-join snapshots and `Sync.attach` to run inside the frame loop. Objects owned by another node are frozen locally (`obj._remote`) so `Scene.tick` skips their physics and joints. Nodes ignore frames from peers that have not completed the handshake, reject spoofed sender ids, cap decompressed payloads at 64 MiB, authenticate with an HMAC challenge when a password is set, and let remote peers write only the variables that were actually shared. Malformed or hostile sync operations are counted in `Sync.rejected` and kept in `Sync.errors` instead of raising. Network protocol version 2.
- `styler.image` now defaults `shades` to a 256-step gradient from a space to `█`, so images come out as monochrome shaded text unless `color=True` is given. The new `bgcolor` argument fills every cell with a background color and blends transparent pixels into it.
- The `rendering` component is merged into `transform`: `show`, `z`, `spaces`, `front()` and `back()` now live on `obj.transform`, and `obj.rendering` no longer exists.
- Per-object `transform.aspect` is now honoured everywhere an object's own geometry is computed (transform, physics, joint, light, force, pen and humanoid) instead of falling back to `scene.aspect`.
- New `humanoid` component: `scene.obj().create(None, x, y, humanoid={'parts': {...}})` builds a jointed, posable figure from a graph of parts. Parts are placed by `at`/`pin` anchors, mirrored with `mirror`, grouped with `group` and animated with `poses` and `cycles`; the figure offers `pose`, `animate`, `velocity`, `jump`, `detach`, `add_part`, `add_parts` and `remove_part`, `ragdoll`.
- Objects and components raise a clear `TypeError` when indexed with something other than a setting name, and are no longer iterable by accident. Unknown names and settings of components an object does not have raise `KeyError`, and `name in obj` reports whether the setting exists.
- `transform.bounce(normal, angle=None, incoming_only=False)` and the new `transform.approaching(normal, angle=None)` let a heading that already leaves the surface stay unchanged.
- New `bouncethreshold` setting (`scene.bouncethreshold` and per-body `physics` setting) for the impact speed below which collisions stop bouncing.
- Callbacks that are bound methods are now called with the right number of arguments in `ontouch`, `onchange` and the other callback hooks.
- Assigning an unknown setting through a component, such as `transform['nope'] = 1`, raises `KeyError` instead of silently creating an attribute.

## 0.1.0

- First public release.
- Python 3.8 or newer.
- The default physics `precision` is `0.5`, which keeps fast objects cheap to simulate. Set `scene.precision` (or an object's `precision`) to change it.
- New `ttyengine.region` module and `Session(region=...)` setting. A region can be a preset (`line`, `column`, `top`, `bottom`, `left`, `right`, `box`, `centered`, `inline`), a tuple, a dict of insets, or use percentages and `start`/`center`/`end` alignment, so the engine can draw a single line, a column or a panel for command-line and text-UI programs.
- `region.inline(rows)` draws below the cursor on the normal screen and scrolls the terminal when needed.
- `session.World(region=...)` gives every world its own part of the session's region.
- `scene.canvas` and `scene.view` replace juggling `termx`, `termy`, `dimx`, `dimy`, `dimxoffset` and `dimyoffset`, which keep working. `Styler.fill` accepts `region=`.
- `termxoffset`, `termyoffset`, `termwidth` and `termheight` are now aliases for the parts of `session.region`. A negative `termwidth` or `termheight` leaves that many cells unused instead of collapsing the region.
- When a session that draws in part of the terminal stops, the cursor returns to where it was.
- Image decoding falls back to ffmpeg for formats the engine cannot read itself (WebP, TIFF, TGA, AVIF, CMYK JPEG and more), and for damaged files it can still recover.
- `styler.image` without `width` or `height` uses a fixed size (80 columns, or the image's own width if smaller) instead of the terminal size.
- `vsync` now presents frames in step with the display refresh through the compositor, and the new `refresh` setting overrides the detected rate. Synchronized output stays, so a frame is still painted atomically.
- The `ffmpeg` session option is honored even when `sound=False`.
- Decoders always raise `ImageError` for bad data, 16-bit PNG transparency keys are compared in full, and invalid GIF code sizes are rejected.
- Releases are published to PyPI automatically when a version tag is pushed.
